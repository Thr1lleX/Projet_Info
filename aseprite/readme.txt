Format 1 tile = 16x16 pixels

1 personnage "normal" doit rentrer dans 1 tile (peut-être légèrement plus petit que 16x16)

Pour couleurs pixels art: au dessus des couleurs, clique sur le dossier (presets)
tape NES et prend le 1er résultat

(idéalement pas plus de 5 couleurs sur un sprite car après devient illisible, mais si tu t'en fous c'est pas grave)

Grille:
View → Grid → 1x1

Symétrie:
View → Symmetrie Options

Raccourcis utiles:
B Pinceau
E Gomme
I Color Picker
G le truc qui fout de la couleur partout 

Vue des Tileset:
View → Tiled Mode → Tiled in Both Axes
